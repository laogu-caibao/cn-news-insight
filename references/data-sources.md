# 数据源（2026-09-29 实测修订）

本 skill 在"关联标的"一步需要用行情接口核对 A 股公司代码，避免张冠李戴。

## 行情接口（用于代码核对）

**Fallback 链**：腾讯 → 新浪 → 网页搜索。接口不可用时，代码后标注「未核对」，**不凭记忆填写**。

### 腾讯行情（备选；部分网络环境 TCP 超时不可用）
```
https://qt.gtimg.cn/q=sz300075
```
返回 `v_sz300075="51~数字政通~300075~..."`，`~` 分隔，位置 1 为公司简称，用于回核名称。

### 新浪行情（主力，需 Referer；返回 GBK 编码）
```
Referer: https://finance.sina.com.cn/
https://hq.sinajs.cn/list=sz300075
```
返回 `var hq_str_sz300075="数字政通, ..."`，逗号分隔，位置 0 为公司简称。
**必须先 `iconv -f GBK -t UTF-8` 转码后再解析**，否则简称乱码导致回核失败。

### 代码前缀规则
深交所（0/3开头）→ `sz`，上交所（6/9开头）→ `sh`，北交所（4/8开头，92开头同样用 `bj`）→ `bj`。

## 降级规则
- 接口可调用：用返回的公司简称与新闻中的公司名回核，一致才采用该代码。
- 接口不可用：代码后标注「未核对」；或改用网页搜索 `{公司名} 股票代码` 交叉确认并注明来源。
- 任何情况下不凭记忆填写代码；无法确认时宁可不写代码，只写公司名并标注。
